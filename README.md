# Atom Studio

通过对话生成和迭代网页应用的 Demo。当前默认运行示例引擎；配置模型后可使用真实 AI 生成。

## 已实现

- 邮箱、昵称和密码注册；邮箱密码登录；退出登录。
- 数据库账号及服务端会话；密码使用 bcrypt（cost 12）加盐哈希；数据库仅保存会话令牌的 SHA-256 摘要。
- HttpOnly、SameSite Cookie，HTTPS 环境启用 Secure；登录有效期 7 天；退出立即撤销当前会话。
- 登录尝试按邮箱限流；Cloudflare 环境额外按可信来源 IP 限流。
- 所有项目读写、版本恢复与分支接口校验账号归属。
- 项目、生成代码、修改记录和版本存入 D1；退出后重新登录可继续访问。
- 应用预览、源码查看、导出 HTML、手机宽度预览与历史版本恢复。
- 生成应用的用户数据通过隔离的 `localStorage` 桥接到 D1，刷新或重新登录后仍可恢复。
- 对话生成时展示需求分析、交互规划、代码校验和版本保存等执行步骤。
- 任意版本可以发布；项目发布后由前端和接口共同锁定，取消发布后才能继续生成或恢复版本。
- 对话生成时展示可折叠的执行步骤；完成后保留需求分析、交互规划、代码校验和版本保存记录。
- 任意历史版本可发布为项目的锁定版本；发布后禁止生成、修改和恢复，取消发布后恢复编辑。

## 延展能力：版本分支

在“版本”中点击“创建分支项目”，即可将指定历史版本复制到独立项目，并自动打开它。之后的修改仅影响新项目。相比单纯回退，这让用户可以同时探索不同产品方向或设计方案，不必覆盖原有成果。

演示：创建待办应用 → 修改主题 → 在版本面板从第一版创建分支 → 修改分支 → 切回原项目，验证原项目未变化。

## 发布锁

点击“发布当前版本”会记录发布版本和发布时间，并把该项目切换为只读状态。发布期间仍可预览、导出和使用应用，但不能生成修改或恢复历史版本；可创建独立分支继续探索。点击“取消发布”后恢复编辑。

## 本地运行

需要 Node.js >= 22.13。

```sh
npm ci
npm run build
# 首次初始化：逐个执行 drizzle/ 中 SQL 文件，仅执行尚未应用的文件。
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_sloppy_major_mapleleaf.sql
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_absent_eddie_brock.sql
npm run dev
```

已初始化数据库不要再次执行相同的建表迁移。本站开发环境已执行以上两次迁移。Sites 生产部署由平台应用迁移；不依赖本地数据库。

## 真实模型

在服务端环境中设置 MODEL_BASE_URL、MODEL_NAME、MODEL_API_KEY。BASE_URL 应为兼容 Chat Completions 服务的 API 根地址，应用追加 `/chat/completions`。密钥不得写入客户端或提交仓库。三项齐备后可在设置中选择真实 AI。

## 当前限制与取舍

- 邮箱当前仅用作账号标识，没有发送验证邮件；尚未提供找回密码、多因素认证和账号管理。
- 真实模型尚未配置或端到端验证，示例模式不是大模型生成。
- 生成应用采用单文件 HTML/CSS/JS，在仅允许脚本的隔离 iframe 中运行，不支持任意外部依赖或后端进程；应用通过项目级存储桥保存最多 50 KB 的字符串键值数据。
- 项目平台的数据库持久化已实现，生成应用内部的数据持久化是下一阶段能力。
- WebMCP 为可选浏览器能力；没有可用验证上下文，未验证其运行契约。
- 当前仅完成本地构建与接口测试，没有完成浏览器交互自动化测试或公开部署。
- 生产部署前需配置模型、评估账号注册与模型使用配额，并在真实托管环境验证密码哈希所需 CPU 配额及访问网络。

后续优先级：真实模型端到端验证 → 生成应用持久化 → 邮件验证与找回密码 → 可分享的只读应用链接。

## AI 调用额度

当前演示档：每个账号滚动 60 秒最多 5 次，每天最多 30 次，同时仅 1 个生成请求；全站每天最多 100 次。北京时间 00:00 重置。可通过 AI_USER_PER_MINUTE、AI_USER_PER_DAY、AI_GLOBAL_PER_DAY 调整，设置为 0 即关闭相关调用；非法配置拒绝放行。密钥未配置时不会预占额度。

所有额度在发出模型请求前，通过同一条原子数据库语句检查并预占，防止并发绕过。次数跨进程重启保留。失败及超时调用不退款，因为服务商可能已产生用量。请求最长等待 90 秒，锁租期 120 秒，异常退出后可自动恢复。不会自动重试模型请求。

单次需求加历史代码最多 24,000 UTF-8 字节（系统提示另计）；最大输出 6,000 tokens。输入过大拒绝发送，不截断旧代码。恢复版本、创建分支和示例引擎不消耗 AI 次数。设置面板显示账号今日使用次数。

这是应用调用量上限，不是账户金额硬上限，不能限制同一 Key 在其他应用的使用。实际费用取决于模型、输入输出用量和服务商计费，确定服务商与模型后再按预算校准限制。API Key 未提供，当前仍无法真实调用模型。
