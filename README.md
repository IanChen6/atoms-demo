# Atom Studio

Atom Studio 是一个通过对话生成、预览、迭代和发布网页应用的 AI Agent 工作台。它提供真实注册登录、可核验的执行记录、版本管理、发布锁、数据持久化和可视化圈选修改。

## 核心能力

- **真实账号系统**：邮箱注册、登录、退出与七天服务端会话；密码使用 bcrypt 加盐哈希。
- **聊天/构建意图路由**：普通问答只进入会话，不创建应用版本；创建、修改和圈选反馈才启动构建流程。
- **真实执行记录**：展示服务端实际发生的意图识别、约束整理、模型调用、产物校验和版本保存；不生成虚构步骤，也不暴露模型的私有推理文本。
- **实时生成反馈**：消息发送后立即出现在会话中，服务端通过 SSE 持续返回执行进度。
- **三栏工作台**：左侧管理会话与已发布应用，中间对话，右侧提供预览、项目文件、版本和应用说明。
- **圈选修改**：在预览中开启圈选模式，点击页面元素后把元素路径、文字和样式上下文附加到下一条修改需求。
- **文件式代码视图**：以 `workspace/index.html`、`README.md` 和 `app.json` 展示当前生成结果；可导出独立 HTML。
- **发布前人工编辑**：未发布应用可以直接修改 HTML 代码、应用名称、介绍和使用说明；代码保存后会形成新的不可变版本。
- **Atoms 验证请求**：每次代码或资料修改都会重置验证状态，用户需手动提交当前版本的验证请求后才能发布。
- **持久化**：账号、项目、消息、版本和发布状态保存到 D1；生成应用中的 `localStorage` 通过隔离桥同步到项目数据。
- **版本与发布**：每次成功构建生成不可变版本，可恢复或创建分支。发布后应用修改被服务端锁定，普通讨论仍可继续；取消发布后恢复编辑。
- **调用保护**：默认每用户每分钟 5 次、每天 30 次、同时 1 次，全站每天 100 次。

## 技术栈

- Next.js 16、React 19、TypeScript
- Tailwind CSS 4、Radix UI、Lucide Icons
- Cloudflare Workers、D1、Drizzle ORM
- 兼容 Chat Completions 的模型服务

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run build
```

首次启动本地数据库时，按文件名顺序执行 `drizzle/` 下尚未应用的迁移，然后启动服务：

```sh
npm run dev
```

Sites 生产环境会在部署时应用数据库迁移，不依赖本地数据库文件。

## 模型配置

复制 `.env.example` 为本地环境文件，并填写服务端变量：

```text
MODEL_BASE_URL=https://example.com/v1
MODEL_NAME=your-model-name
MODEL_API_KEY=your-api-key
AI_USER_PER_MINUTE=5
AI_USER_PER_DAY=30
AI_GLOBAL_PER_DAY=100
```

环境变量值不要额外包裹引号。密钥只放在服务端环境，不能写入客户端或提交仓库。应用会在 `MODEL_BASE_URL` 后追加 `/chat/completions`。

## 使用流程

1. 注册并登录。
2. 普通聊天可直接发送；Enter 发送，Shift+Enter 换行。
3. 用“构建一个……”描述应用及核心交互，在会话中查看本次请求真实发生的执行步骤。
4. 在预览中体验应用；需要局部修改时开启“圈选修改”，点击元素并在对话框补充意见。
5. 在“代码”中手动编辑 HTML，或在“说明”中修改应用名称、介绍和使用说明。保存后验证状态会回到待提交。
6. 点击“提交 Atoms 验证”，确认当前版本已进入验证流程后发布。发布期间应用保持只读，取消发布后才能继续修改。
7. 从“我的应用”进入独立应用详情页，查看应用说明、使用应用、导出源码或取消发布，不显示构建对话。

## 安全与边界

- 生成结果是单文件 HTML/CSS/JavaScript，运行在仅允许脚本的隔离 iframe 中。
- 生成应用不能访问外部网络、弹窗、导航、认证、支付或任意后端进程。
- 圈选模式只传递元素标签、选择路径、类名和截断后的可见文字，不执行选中内容中的指令。
- 项目接口、版本、发布和应用数据均校验账号归属。
- 额度限制用于控制此应用发出的调用次数，不等同于模型服务商的金额预算上限。

## 当前限制

- 邮箱只作为账号标识，尚未接入邮件验证、找回密码和多因素认证。
- 代码视图展示的是便于理解和导出的虚拟项目结构，实际生成物仍以可移植的单文件 HTML 保存。
- 发布代表工作台内的版本锁定与“我的应用”管理，目前没有为每个生成应用创建独立公开域名。
